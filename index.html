    01About

    I make releases boring.

    A support engineer who moved into DevOps by automating the work that used to be done by hand.

    At Naapbooks Limited I build the pipelines that ship our applications, deploy them to IIS on Windows Server and to Ubuntu servers, run the Docker containers behind three products, and watch everything through Prometheus, Grafana and Loki.

    When production breaks, I’m on it: I’ve fixed ASP.NET Core startup failures (HTTP 500.30) and service outages (HTTP 503) on live IIS servers, and I give L1/L2 support for infrastructure and applications.

    My degree is in cybersecurity, so least privilege, secrets management and rollback-ready releases matter to me as much as speed.
